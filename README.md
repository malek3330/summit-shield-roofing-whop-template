This production US roofing website template built on Whop Websites delivers the complete high-ticket inspection → deposit → final balance lifecycle using a single-file rebrandable architecture (`src/config/roofingTemplate.ts`). Three real Whop plans—a $149 19-Point Inspection (`/book/inspection`), a $299 Flat-Rate Roof Tune-Up (`/book/tune-up`), and a $500 Project Deposit (`/deposit`)—power dedicated `@whop/elements-react` checkouts combining `ExpressCheckoutElement` (Apple Pay / Google Pay), `EmailElement`, `PaymentElement` (surfacing cards and Klarna/Afterpay/Splitit financing automatically), `CheckoutElement`, and the required `BrandingElement`, plus an interactive `Test Card (4242)` Sandbox mode switcher. During the $500 project deposit, `<Payments mode="setup">` creates a Whop `SetupIntent` to authorize and save the homeowner's payment method on file, charges the scheduling deposit, and redirects to `/checkout/return` where an official printable tax receipt can be printed or saved as PDF, and the closing roof balance can be settled immediately via the Whop Invoices API (`Auto-Charge Saved Card` off-session billing or `Send Manual Invoice` hosted payment link and PDF). Quote requests submit to the Whop Leads and Events APIs with public response redaction and an admin-authenticated Contractor Portal (`Leads` CRM & `Invoices`), while `whop.track` fires verifiable custom conversion events (`service_viewed`, `deposit_started`, and `estimate_requested`) alongside automatic `.whop.site` telemetry.
